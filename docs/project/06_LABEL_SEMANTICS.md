**整理日期：** 2026-11-28

**状态：** 两套标签语义已由用户确认；仅作语义登记，不改动任何数据、Mask、Manifest、Fold、dataset.json 或像素值

**权威性：** 本文件的标签语义以用户于 2026-11-28 的确认内容为准。早孕期 GT 的读取、几何后处理与评价细节仍以 `02_GT_PROTOCOL.md` 和原始 `CARDIAC_AXIS_DATA_READING_SPEC_v1.md` 为准；本文件不重新定义几何算法。

---

## 0. 最重要的原则

1. **两套标签是两套独立体系。** 早孕期（Dataset501，7 类）与中孕期（Dataset503，10 类）的标签由不同标注体系产生，**相同数字 ID 不代表相同解剖语义**。
2. **不得按 ID 数字强行对齐或共享监督。** 跨孕周迁移只能依据本文件列出的真实语义逐项判断，不能因为 ID 数字相同就直接共享。
3. **保留历史实验实际使用的原始 Label ID。** 既有 E0/E1/E2/E3/M1/M1.1/HET-PSM 的标签 ID、dataset.json、输出头维度、指标列名都不因本文件而重新映射或重编号。
4. **中孕期 ID8 是“未知区域”，与心轴角测算无关。** 不赋予其任何解剖名称，不推测其边界定义。
5. **本文件是语义登记，不是数据修改授权。** 任何标签合并、映射、重采样或监督范围变更都需要单独的用户批准。

## 3. 相同数字 ≠ 相同语义（对照表）

| 数字 ID | 早孕期语义（Dataset501） | 中孕期语义（Dataset503） | 是否可视为同一结构 |
|---:|---|---|---|
| 0 | 背景 | 背景 | 是（都是背景） |
| 1 | 胸椎 | 左心房 | **否** |
| 2 | 左侧肋骨 | 左心室 | **否** |
| 3 | 右侧肋骨 | 右心房 | **否** |
| 4 | 左侧心脏 | 右心室 | **否** |
| 5 | 右侧心脏 | 胸椎 | **否** |
| 6 | 胸腔 | 胸腔 | 概念相同，但标注体系/边界不同，仍需逐项核实 |
| 7 | —（早孕无此 ID） | 心内缘 | 早孕不存在 |
| 8 | —（早孕无此 ID） | 未知区域 | 早孕不存在 |
| 9 | —（早孕无此 ID） | 室间隔 | 早孕不存在 |

关键警示：

- 唯一“数字相同且概念相同”的是 **ID0 背景**；中孕 **ID6 胸腔**与早孕 **ID6 胸腔**概念一致，但来自不同标注体系，几何定义与边界未必相同。
- **早孕 ID1（胸椎）对应的是中孕 ID5（胸椎）**，而不是中孕 ID1（左心房）；早孕 ID5（右侧心脏）与中孕 ID5（胸椎）数字相同但语义完全不同。这是最容易被 ID 数字误导的地方。
- 任何跨孕周监督、共享 encoder/decoder、辅助头目标设计，都必须基于本表的语义，而不是 ID 相等。
